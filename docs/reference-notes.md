# 参考サイト分析メモ

## 1. 現行サイト: aslabpro.com（アスラボ）
マインクラフトを活用したプログラミングスクール。

- 開設背景：理科大生がプログラミング学習で苦労した経験から、葛飾区金町に教室を開設
- 4つの特徴：
  1. マインクラフト活用カリキュラム（ゲーム内ミッションで論理的思考・問題解決力を習得）
  2. 少人数制指導（個別ペース対応、初心者もサポート）
  3. 復習テスト（ペーパーテストで理解度を測定、必要に応じ再指導）
  4. 指導報告書（毎授業後に保護者へ進捗報告／金町校を除く）
- 免責事項：Mojang社・Microsoft社とは無関係

## 2. 参考サイト①: earth-academy.jp（アースアカデミー）
複数校舎を展開する学習塾。ページ構成・情報設計の参考にする。

- ヘッダー：Home / About / Courses / Location / Tuition&Timetable / FAQ / News / Contact
- メインビジュアル：「『学ぶ』ことが好きになる学習塾」というキャッチコピー＋ブランドロゴ
- 教育方針：「『学ぶ』ことが『好き』になれば何にでもなれるよ」＋理念4要素（向上・探求・信頼・希望）
- 教室案内：東京・大阪・千葉に多数の校舎（公津の杜・佐倉・四街道・旭・吹田・豊中長興寺・金町・新小岩・西葛西）、最寄り駅情報を記載
- コース案内：通常個別指導（2:1）／マンツーマン指導（1:1）、予習型授業を重視
- ニュース：新校舎開校情報、東京理科大学オープンカレッジ参加案内など
- お問い合わせ：電話番号＋問い合わせフォームへの導線
- フッター：著作権表示、プライバシーポリシー、ナビ再掲

### アースラボへの応用ポイント
- ページを分割し、ナビゲーションで整理する情報設計をそのまま踏襲できる
- 「教育方針」を明文化したセクションを追加すると信頼感が増す
- 複数教室がある場合は教室案内ページで一覧化

## 3. 参考サイト②: craft-plus.jp（クラフトプラス）※Features中心
マインクラフト教室のフランチャイズ向けサービスサイト。特長セクションの見せ方を参考にする。

- ヘッダー：特長 / 料金 / FAQ / ブログ / AIコーディング / 無料トライアル
- ヒーロー：「マイクラで始める 低コスト・高収益のプログラミング教室」＋料金の即時提示（基本11,000円＋生徒1,980円、加盟金ゼロ）
- Featuresセクション：4つの強みをカード形式で並列表示
  1. 完全オリジナルワールド（教育版マインクラフト上の専用ワールドで差別化）
  2. 自習型PDF教材（自学自習で継続率向上）
  3. 未経験スタッフで運営可能（プログラミング知識不要）
  4. ホワイトラベル対応（独自コース名で運営可、ロイヤリティなし）
- その他：大手FC比較表、導入事例、カリキュラム詳細、料金シミュレーション、導入フロー、FAQ、無料トライアルフォーム

### アースラボへの応用ポイント
- トップページに「選ばれる理由（特長）」を4つ程度のカードでビジュアル訴求すると分かりやすい
- 料金や無料体験への導線をヒーロー直下に置く構成は問い合わせ増加に有効
- カリキュラム・導入事例など「証拠」セクションを増やすとスクールの信頼性UP

## サイト構成案（今回のリニューアルで採用）
earth-academy.jp型の複数ページ構成をベースに、craft-plus.jpの特長セクションの見せ方をトップページに取り入れる。

| ページ | 内容 |
|---|---|
| index.html | ヒーロー／教育方針／特長（カード4つ）／コース概要／教室案内（抜粋）／ニュース（抜粋）／お問い合わせ導線 |
| about.html | 開設背景・理念・代表メッセージ |
| courses.html | マインクラフト活用カリキュラムの詳細、指導形態、対象年齢など |
| locations.html | 教室一覧（住所・最寄り駅・地図） |
| tuition.html | 料金・時間割 |
| faq.html | よくある質問 |
| news.html | お知らせ一覧 |
| contact.html | 電話番号・問い合わせフォーム |

※実際のコピー・料金・教室数などはクライアント（現行アスラボ）から要ヒアリング。雛形には仮のプレースホルダーを入れる。
